# Comercializadora y Transportes JP

Réplica estática del sitio de Comercializadora y Transportes JP. Abre esta carpeta en VS Code y carga `index.html` en el navegador. También puedes servir la carpeta con cualquier servidor HTTP estático. El proyecto funciona sin instalar dependencias ni ejecutar una compilación.

- `index.html` contiene el contenido, el catálogo y el formulario.
- `styles.css` contiene el diseño y los ajustes para pantallas móviles.
- `main.js` controla el menú, los botones de cotización y el borrador de correo.

La cotización se prepara en el navegador. Puedes copiarla o abrir un borrador en tu aplicación de correo.
